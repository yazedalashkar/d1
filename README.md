# أكاديمية قواعد معطيات 1 التفاعلية (DB1 Interactive Academy)
منصة تعليمية تفاعلية متدرجة من الصفر لشرح المحاضرات العملية (2، 3، 4، 5، 6) لمادة قواعد معطيات 1 — جامعة حمص (معهد تقنيات الحاسوب - السنة الثانية).

## محتويات المشروع الجاهز للنشر على Vercel / Netlify
- `index.html`: التطبيق التفاعلي الكامل (16 محطة تعليمية متدرجة + رسومات SVG تفاعلية + محاكي SQL حي + فحص تجريبي من 30 سؤالاً).
- `vercel.json`: إعدادات التوجيه والروابط النظيفة الخاصة بمنصة Vercel.
- `package.json`: ملف تعريف المشروع الجاهز للنشر المباشر.

## طريقة الرفع على Vercel
1. ارفع هذا المجلد إلى مستودع GitHub خاص بك، ثم من لوحة تحكم Vercel اختر **Add New Project** واستورد المستودع واضغط **Deploy**.
2. أو عبر الطرفية (Terminal): شغّل `npx vercel --prod` داخل المجلد.
